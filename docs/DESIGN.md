# UI / UX Design & Workflow Specification

### 1. Aesthetic & Design System
- **Theme:** Minimalist dark mode (Slate/Zinc palette) tailored for engineers and deep-work environments.
- **Accent:** Electric Blue / Amber for cues, habit streaks, and active states.
- **Typography:** Inter / JetBrains Mono for code blocks and logs.

### 2. Core Views
1. **The Context Stream (Workspace / Capture Hub):**
   - Quick raw-input terminal: Paste raw markdown notes, code snippets, or daily brain dumps (`Ctrl + Enter` to parse).
   - Real-time extractor sidecar: Shows parsed tasks and detected micro-habits side-by-side with raw input.
2. **Habit Flow & Anchor Tracker:**
   - List of atomic habits anchored to triggers.
   - Visual completion matrix and streak heatmap.
3. **Daily Action Queue:**
   - Filtered, prioritized task list grouped by context tags (`@work`, `@academic`, `@dev`).
